# Holdem Flicker · 프리플랍 GTO 암기 트레이너

6-max 100bb 캐시 게임 기준의 **프리플랍 GTO 레인지**를 카드 플래시 방식으로 암기하는 모바일 웹앱입니다.

- **훈련 (플래시카드 세션)**: 덱(전체 / 오픈 / 오픈 대응 / 3벳 대응 / 4벳·올인 / 내 약점)과 포지션을 고르면 10·20·40장 세션이 시작됩니다. 핸드가 나오면 **폴드 · 콜 · 3벳 같은 액션 버튼**으로 직접 고르고, 고르는 즉시 타이머가 멈추고 정답과 한 줄 해설이 나오며(다음 카드는 **다음** 버튼으로 넘어갑니다) 화면 배경이 정답(청록) / 오답(호박) / 시간 초과(남색)로 바뀝니다. 생각 시간은 숫자로 보이고(보통 8초, 천천히 12초, 빠르게 5초), 답을 고른 뒤에는 생각 타이머가 멈추고, **다음** 버튼이 버튼 안에서 5초를 세다가(숫자 + 줄어드는 게이지) 그대로 두면 자동으로 다음 카드로 넘어가요. 해설이나 차트를 열거나 ◀·일시정지·헷갈려요로 표시를 누르거나 카드를 건드리면 카운트는 그 카드에서 완전히 멈추고, 다음 버튼을 직접 눌러야 넘어갑니다(직접 넘기기를 켜 두면 처음부터 5초 자동 진행이 없어요). 정답 화면의 **차트** 버튼을 누르면 그 상황의 GTO 차트(액션 비율, 13×13 레인지에서 내 패 위치, 차트 요약)를 바로 볼 수 있고(순간기억은 1.5초마다 화면이 바뀌어 이 버튼을 두지 않았습니다), 거기서 **전체 차트 보기**로 넘어가면 세션은 일시정지되어 둘러보는 동안 공부 시간이 늘지 않습니다. 시간 안에 못 고르면 시간 초과로 기록됩니다. **순간기억(1.5초)** 프리셋과 답을 처음부터 같이 보는 **노출 모드**는 선택 없이 훑어보기만 합니다. 화면을 **길게 누르면 타이머가 멈추고 해설**이 나옵니다. 정답이면 알아요, 오답·시간 초과면 헷갈려요로 간격 반복(SRS) 큐에 반영되어 다음 세션에 복습으로 돌아오고, 맞혔지만 자신 없는 카드는 "헷갈려요로 표시"로 바꿀 수 있습니다. 세션이 끝나면 요약(정답 비율, 약점 상황, 틀린 카드)과 함께 "틀린 것만 다시", "퀴즈로 확인"을 고를 수 있습니다.
- **홈**: 오늘 목표 링, 연속 일수, 외웠어요/배우는 중/새 카드, 약한 상황, 최근 12주 히트맵.
- **퀴즈**: 같은 SRS 큐에서 10문제씩. 직접 액션을 고르고 정답률·연속 정답을 기록합니다.
- **차트**: 상황별 13×13 레인지 차트, 셀별 해설, "이 상황으로 훈련하기", 내 기록 오버레이.
- **해설**: 왜 그 액션인지(레인지, 블로커, 포지션, 팟 오즈)와 **폴드가 아닐 때 플랍에서 확인할 것**(레인지 우위, 넛 우위, SPR, 보드 텍스처, 플레이 계획).
- 카드는 수티드/오프수트 구분이 한눈에 보이도록 **♠와 ♦만** 사용합니다. 좌석은 둥근 테이블 대신 **UTG → BB 한 줄**로 보여 주고 "앞 3명 폴드 · 뒤 1명 남음"처럼 설명합니다.
- 모바일 전용 UI입니다(세로 360–430px 기준). iOS 26 Liquid Glass 느낌의 반투명 패널과 떠 있는 탭 바, 짧고 친근한 한국어 문구를 씁니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173/holdem-flicker/
npm test         # 레인지 표기 파서 + 차트 무결성 테스트
npm run build    # dist/

npm run preview                                                   # 빌드 결과를 :4173 에서 서빙
npm run e2e -- http://localhost:4173/holdem-flicker/ work/e2e     # 폰 뷰포트 스모크 테스트
npm run audit:layout -- http://localhost:4173/holdem-flicker/     # 마진·박스모델 감사 (360/390/430)
npm run fonts                                                     # Noto Sans KR 파일 다시 받기
```

## 폰트

본문 폰트는 **Noto Sans KR 가변(굵기 400~800)** 이고, `public/fonts/noto-sans-kr/` 에 **셀프 호스팅**합니다.
Google Fonts 가 내려주는 woff2 서브셋 124개를 그대로 담아 두고 `src/styles/fonts.css` 가 같은 `unicode-range` 로
연결하므로, 브라우저는 화면에 실제로 쓰는 글자의 조각만 받아옵니다(홈 화면 기준 11개, 약 370KB).
런타임에 제3자로 나가는 요청이 없어서 사내망·오프라인·프록시 환경에서도 글꼴이 항상 뜹니다.
폰트 버전이 올라갔을 때만 `npm run fonts` 로 다시 받으면 됩니다(`src/styles/fonts.css` 는 그 스크립트가 만듭니다).

폰트 자체의 라이선스는 **SIL Open Font License 1.1** 이고 전문은 `public/fonts/noto-sans-kr/OFL.txt` 에 함께 담았습니다.

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 `gh-pages` 브랜치에 올립니다.
저장소 Settings → Pages → Source가 **Deploy from a branch · gh-pages / (root)** 이면 됩니다.
배포 주소: `https://<owner>.github.io/holdem-flicker/`

## 데이터에 대해

레인지는 널리 공개된 솔버 결과(GTO Wizard·Upswing 계열, 6-max 100bb, 2.5bb 오픈)를 **암기하기 쉽게 근사**한 것입니다.
실제 솔버 출력은 레이크·사이징·상대 레인지에 따라 달라지며, 혼합 빈도 핸드는 가장 높은 빈도의 액션을 정답으로 표시합니다.
차트는 `src/poker/data/*.ts`에서 `docs/RANGE_SPEC.md`의 표기법으로 직접 수정할 수 있습니다.
