# 차트를 책(MPT 5장)의 균형 전략에 맞추기 — 구성 명세

> 사용자 요청(2026-11-10): "차이를 없애고 차트를 책의 균형 전략에 맞춰."
> 근거: 학습노트 `5장 6-max 캐시게임 균형 전략 (100bb)`(노트 5장 1~5절)과 `4장 프리플랍`(노트 4장 6·7·10절).
> 이 문서가 차트 74개를 다시 만드는 기준이고, `tests/book-charts.test.ts`가 아래 §3의 숫자와 규칙을 그대로 검사해요.

## 0. 무엇을 할 수 있고 무엇을 할 수 없나

- 노트는 **비율 · 크기 · 원리 · 몇몇 패의 예**를 줘요. 패 하나하나의 빈도표는 없어요(노트 5장 6절: "이 노트는 차트를 옮기지 않았으니, 정확한 핸드별 빈도는 원서의 차트를 확인하십시오"). 원서의 차트를 합법적으로 볼 수 있는 공개 자료도 없어요.
- 그래서 새 차트는 **책이 밝힌 숫자와 규칙을 하나도 어기지 않도록** 다시 만들고, 책이 말하지 않는 패 단위 선택은 다음 순서로 정해요.
  1. 책의 원리(네 가지 힘, 블로커, 지배, 실현, 보드 커버리지, 양극화/선형).
  2. 지금 차트(공개 솔버 결과를 단순화한 것)의 순서 — 섞인 칸이 경계예요.
  3. 공개 솔버 자료의 일반적인 수치(조사 결과 §5, 출처 표기).
- 안내 문구도 바꿔요: "책(MPT) 5장의 비율·크기·원리에 맞춰 만든 차트예요. 패 하나하나의 빈도는 원서 차트와 다를 수 있어요."
- 칸 빈도는 지금처럼 25% 단위예요. 책이 말한 "솔버 잔여물(53s·K6s 같은 낯선 소량 섞기)"은 넣지 않아요(노트 5장 6절).

## 2. 액션 모델

- **SB 첫 진입에 `림프`를 더해요**: `rfi:SB` = 폴드 · 림프(1bb까지 맞추기) · 레이즈(3bb). 다른 자리는 레이즈 아니면 폴드(노트 5장 2절, 4장 7절).
- **`vs_limp` + BB = "SB가 림프했고 BB 차례"**: 책의 균형에서 림프하는 자리는 SB뿐이에요. BB는 3.5bb로 레이즈하거나 체크해요.
- `vs_limp` + HJ·CO·BTN·SB는 그대로 "앞에서 한 명(약한 플레이어)이 림프" — 책의 고립 조언(노트 4장 7절)을 따르는 기본값이에요.
- 림프 뒤 BB가 레이즈했을 때 SB의 대응(재레이즈 13bb 선형, AA는 콜로 슬로우플레이, KK·QQ·AK는 BB의 4벳에 올인)은 **이번 범위가 아니에요** — 새 상황 종류가 필요해서, SB 림프 범위의 구성(트랩 포함)과 해설에만 반영해요.

## 4. 사슬 일관성

- `vs_3bet`에서 도달하는 칸 = 그 자리의 `rfi` 레이즈 칸(림프 칸은 아니에요). `vs_4bet` = `vs_open` 3벳 칸, `vs_5bet` = `vs_3bet` 4벳 칸.
- 그래서 고치는 순서: RFI → 오픈 대응 → 3벳 대응 → 4벳 대응 → 5벳 대응. 콜드 4벳과 림프 대응은 따로.
- "오픈한 패의 %"·"3벳한 패의 %" 목표는 앞 차트가 정해진 다음에 맞춰요.

## 6. 테스트 (`tests/book-charts.test.ts`)

§3의 굵은 숫자와 규칙마다 테스트 하나. 예:
- RFI 폭: UTG 17±0.5, HJ 21±0.5, CO 28±0.5, BTN 43±0.5, SB 림프 38±1 · 레이즈 24±1.
- BTN이 책의 목록을 전부 오픈하고 A3o·A2o·K7o를 오픈하지 않음.
- HJ·CO·SB 오픈 대응(SB는 UTG·HJ·CO 상대) 콜 0.
- HJ vs UTG 3벳 ≤ 8%, CO vs UTG = HJ+0.5±0.5, CO vs HJ > CO vs UTG.
- BTN 콜 5~7%이고 UTG ≥ HJ ≥ CO, 3벳 7 · 9 · 12(±1).
- SB vs BTN 3벳 15±1.
- BB vs UTG: A9o 폴드, K2s 콜(주 액션), BB vs CO: K8o 주로 폴드.
- 3벳 대응 4벳 비율(오픈한 패 중): OOP vs IP ≈ 22±3, IP vs 블라인드 ≈ 10±3.
- 4벳 대응: IP 3벳한 쪽은 올인 ≈ 18±4(3벳한 패 중)이고 콜 > 올인, AA 콜 ≥ 50%, QQ·JJ 등 KK보다 약한 페어는 주로 콜.
