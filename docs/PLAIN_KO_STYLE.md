# 쉬운 한국어 해설 스타일 가이드 (중학생 기준)

목표: 포커를 처음 배우는 중학생이 읽어도 이해되는 해설. 짧은 문장, 일상어, 구체적인 예시.

## 문장 규칙
- 한 문장은 25자 안팎, 한 가지 생각만. "~합니다" 대신 "~해요/~이에요" 체로 부드럽게.
- 영어 약어·전문용어는 **처음 나올 때 괄호로 뜻을 붙인다**. 두 번째부터는 용어만 써도 된다.
- 숫자는 꼭 필요할 때만. 퍼센트는 "10번 중 3번쯤"처럼 감이 오게 바꿔도 좋다.
- 각 해설에 **예시를 최소 1개**: 실제 카드로 보여 준다. 예: "내 K♠Q♦ 상대 A♠Q♠ → 둘 다 Q를 맞추면 내가 져요."
- 왜 그런지 이유는 "~라서", "~때문에"로 이어 준다. 결론 → 이유 → 예시 순서.

## 용어 풀이 표 (이 표현을 그대로 쓴다)
| 용어 | 쉬운 말 |
|---|---|
| 레인지 | 그 자리에서 보통 플레이하는 손패 묶음 |
| 오픈(레이즈) | 아무도 안 올렸을 때 내가 먼저 올리는 것 |
| 3벳 | 상대가 올린 걸 내가 다시 올리는 것 |
| 4벳 | 3벳을 받은 사람이 또 올리는 것 |
| 5벳 / 올인 | 남은 칩을 전부 거는 것 |
| 콜 | 상대가 건 만큼 따라 내는 것 |
| 폴드 | 패를 접고 이번 판을 포기하는 것 |
| 포지션 / 인포지션 | 플랍 뒤에 나중에 행동할 수 있는 유리한 자리 (상대가 먼저 움직이니 정보를 더 얻어요) |
| 아웃오브포지션 | 내가 먼저 행동해야 하는 불리한 자리 |
| 블로커 | 내가 쥔 카드 때문에 상대가 그 강한 패를 가질 확률이 줄어드는 것 (예: 내가 A를 들면 상대가 AA일 확률이 반으로 줄어요) |
| 도미네이트 | 같은 카드를 맞춰도 옆 카드(킥커)가 낮아서 지는 상황 |
| 킥커 | 짝을 맞춘 카드 옆의 나머지 카드. 승부가 같으면 킥커로 갈려요 |
| 팟 오즈 | 내야 하는 돈에 비해 딸 수 있는 돈의 비율. 싸게 볼수록 넓게 콜해도 돼요 |
| 임플라이드 오즈 | 지금은 손해 같아도, 좋은 패가 완성되면 크게 딸 수 있는 가능성 |
| 셋마이닝 | 포켓페어로 플랍에서 셋(같은 숫자 3장)을 노리는 것. 플랍에서 셋이 될 확률은 약 8분의 1이에요 |
| 에퀴티 → "이길 확률" | 지금 패가 끝까지 갔을 때 이길 확률 |
| 폴드 에퀴티 → "상대가 접을 확률" | 내가 올렸을 때 상대가 접어서 그냥 이길 가능성 |
| 밸류(벳) | 내가 앞서 있다고 보고 돈을 더 받으려고 거는 것 |
| 블러프 | 약한 패로 상대를 접게 하려고 거는 것 |
| 세미 블러프 | 지금은 약하지만 더 맞으면 강해지는 패로 거는 블러프 |
| 넛 | 지금 나올 수 있는 가장 강한 패 |
| 드로우 | 한 장만 더 맞으면 완성되는 패 (예: 같은 무늬 4장 → 플러시 드로우) |
| 백도어 | 두 장을 더 맞아야 완성되는 패. 가능성은 낮지만 덤으로 생각해요 |
| 수티드 | 두 장이 같은 무늬 (♠♠ 또는 ♦♦) |
| 오프수트 | 두 장이 다른 무늬 |
| 커넥터 | 숫자가 이어진 두 장 (예: 8♠7♠) |
| 갭퍼 | 숫자 사이가 한두 칸 비는 두 장 (예: 9♠7♠) |
| 브로드웨이 | 10·J·Q·K·A처럼 큰 카드 두 장 |
| 휠 에이스 | A와 2~5처럼 A에 작은 카드가 붙은 패. A-2-3-4-5 스트레이트가 될 수 있어요 |
| 포켓페어 | 손에 든 두 장이 같은 숫자 |
| 오버페어 | 보드(공용 카드)보다 높은 포켓페어 |
| 탑페어 | 보드에서 제일 높은 카드와 짝을 맞춘 것 |
| 셋 | 포켓페어 + 보드 한 장으로 같은 숫자 3장 |
| 보드 / 플랍 | 가운데 깔리는 공용 카드 / 그중 처음 3장 |
| 드라이 보드 | 드로우가 거의 없는 보드 (예: K♠7♦2♠처럼 서로 안 이어짐) |
| 웻 보드 | 플러시·스트레이트 드로우가 많은 보드 (예: 9♠8♠7♦) |
| c-bet (컨티뉴에이션 벳) | 프리플랍에서 올린 사람이 플랍에서도 이어서 거는 것 |
| 체크 | 돈을 안 걸고 차례를 넘기는 것 |
| 체크-레이즈 | 일부러 체크했다가 상대가 걸면 올리는 것 |
| 스퀴즈 | 누가 올리고 누가 콜한 뒤에 내가 크게 올리는 것 |
| SPR | 남은 칩 ÷ 팟 크기. 작을수록 올인이 쉽게 나와요 |
| 어그레서 | 마지막에 올린 사람 |
| 콜러 | 따라 낸 사람 |
| 헤즈업 | 둘만 남은 상황 |
| 리버스 임플라이드 오즈 | 패를 맞췄는데도 더 큰 패에 져서 크게 잃는 위험 |
| 솔버 / GTO | 컴퓨터가 계산한 '가장 손해 안 보는 플레이'. 이 앱의 정답 기준이에요 |
| 혼합(믹스) | 같은 패로 어떤 땐 올리고 어떤 땐 콜하는 것. 정답은 더 자주 하는 쪽 |

## 예시 만드는 법
- 항상 실제 카드 2장으로: "내 A♠5♠", "상대가 자주 드는 A♦K♠".
- 이기는/지는 장면을 한 줄로: "플랍에 A가 뜨면 둘 다 탑페어지만 킥커 K에 져요."
- 숫자 감각: "10번 중 3번쯤 이겨요", "플랍에서 셋이 될 확률은 8분의 1".
